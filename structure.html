WhatsApp API technical theme for every new page

Use homepage.html as the visual reference for future pages. Keep the sitemap and page plans below; apply this theme to each page type. External reference sites inform structure and interactions; the current 11za homepage defines the visual direction.

Default for all new pages: a technical WhatsApp CRM atmosphere with mint surfaces, visible chat / chatbot / API motifs, circuit routes, connected workflows, white content panels and selective dark console bands. Every section should belong to this system; vary the treatment by purpose.

Palette & typography

Plus Jakarta Sans, weights 500–800. Navy #0D163F, primary green #09AF72, deep green #0A8A66, mint #E5FFF2, light #F0FAF4, soft #E4F5EC, dark green #063E32. Use red for issues or LIVE indicators.

Technical backgrounds

Reuse crm-network.svg for hero edges and whatsapp-api-pattern.svg for repeated chat, bot, API, analytics and connection motifs. Grid spacing 48 px; motif tile 640 × 480 px. Keep the middle quieter behind copy.

Panels & hierarchy

White-to-mint panels, green borders / top accents, 16–26 px corner radii, restrained green shadows. Keep actual screenshots opaque and sharply framed. Use eyebrow badges with a green node, bold navy headings, pill CTAs and WhatsApp-style conversation bubbles.

Responsive & accessible

Use a 1200 px content container, at least 20 px side gutters and 64–112 px section spacing. Stack columns on small screens. Reduce motif tiles to 480 × 360 px and opacity to .36 on mobile. Decorative layers must not capture clicks; keep text contrast and visible keyboard focus. Respect reduced motion.

Section treatment by purpose

Section Background / component treatment Homepage reference
Hero Mint glow, circuit network edges, quiet center, large product or conversation preview. Product hero
Problems, industries, comparison, pricing, FAQ Mint grid with visible but low-contrast API motifs; white panels; green headers or selected states. Industries · Pricing
Features, integrations, stories, tools Richer mint automation canvas; framed screenshots, bot/chat motifs and light input panels. Feature pillars · Automations
Workflow / onboarding Dark green grid, mint text, white step cards; dashed connections on a single desktop row. Remove connectors when cards wrap. Onboarding
AI, calculator outputs, final CTA Navy console surface with green glow and API motifs. Use za-console; white text and mint supporting text. AI Calls · Calculator
Footer / long reading / forms Light mint with quieter motifs. Put articles and form fields on opaque readable panels. Homepage footer

Reusable implementation

Load assets/whatsapp-api-theme.css on new pages, then apply its classes. Resolve the stylesheet URL relative to the new page; SVG URLs inside the stylesheet already resolve from the assets folder. These classes supply theme surfaces; reuse the homepage layout, typography, buttons and responsive components as needed. 

<link rel="stylesheet" href="assets/whatsapp-api-theme.css">
